# Charmy · Calendário editorial

Planejamento de posts para **dezembro de 2026**, inspirado na apresentação da Charmy (lilás, rosa, listras e tipografia editorial).

Site estático sem dependências. Execute `python -m http.server 8000 --directory dist` e abra http://localhost:8000.

Inclui calendário e lista, banco de ideias, criação/edição/exclusão de posts, filtros por canal/status e busca, além de importação/exportação JSON. As 15 sugestões iniciais são rascunhos, todos com status Ideia. Dados são salvos no localStorage do navegador, sem sincronização entre dispositivos. Exporte JSON para backup.

Nenhuma integração publica posts nas redes sociais. Site usa Google Fonts com fontes de fallback.
